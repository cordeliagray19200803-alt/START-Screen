============================================================
緊急・災害時 医療情報アプリ（NFC・PWA版）
============================================================

【この一式でできること】
・スマートフォン／パソコンで医療情報を登録・編集
・端末内へ自動保存（IndexedDB）
・一度読み込んだ後は、圏外でもアプリを開いて表示・編集
・表示画面をブラウザの印刷機能でPDF保存
・Supabaseを設定すると、別のスマートフォンからNFC用URLで表示
・公開用データはEdge Function内で暗号化して保存

------------------------------------------------------------
1. まずGitHub Pagesへ置く
------------------------------------------------------------
このフォルダ内のファイルをGitHubリポジトリの公開フォルダへ置きます。
例：
https://ユーザー名.github.io/medical-info/

index.htmlを開いて動作を確認してください。

------------------------------------------------------------
2. アプリとして使う
------------------------------------------------------------
iPhone：Safariの共有メニュー →「ホーム画面に追加」
Android：ブラウザメニュー →「アプリをインストール」
パソコン：アドレスバーまたはブラウザメニューのインストール

一度オンラインで開いた後は、静的画面と端末内データをオフラインで表示できます。

------------------------------------------------------------
3. NFCを別のスマートフォンで使うには
------------------------------------------------------------
端末内保存だけでは、別のスマートフォンから医療情報を読めません。
Supabase設定後に表示される「NFCタグへ書き込む固定URL」をタグへ書き込みます。

初回アクセス時に完全な圏外の場合、別端末はクラウド情報を取得できません。
本人の端末では、事前に開いてあればオフライン表示できます。

------------------------------------------------------------
4. Supabase設定
------------------------------------------------------------
1) Supabaseで専用プロジェクトを作成
2) SQL Editorで supabase-setup.sql を実行
3) Supabase CLIで、このフォルダのsupabase/functionsを配置
4) 暗号鍵をSecretsへ登録

MEDICAL_DATA_KEY=$(openssl rand -base64 32)
AUDIT_HASH_KEY=$(openssl rand -base64 32)

supabase secrets set \
  MEDICAL_DATA_KEY="$MEDICAL_DATA_KEY" \
  AUDIT_HASH_KEY="$AUDIT_HASH_KEY" \
  ALLOWED_ORIGINS="https://あなたのGitHubユーザー名.github.io"

5) Edge Functionsを配置
supabase functions deploy profile --no-verify-jwt
supabase functions deploy emergency --no-verify-jwt

6) cloud-config.jsに次を設定
・Project URL
・Publishable key（旧anon key）

service_role key、暗号鍵、DBパスワードは絶対にGitHubへ置かないでください。

------------------------------------------------------------
5. 認証設定
------------------------------------------------------------
Supabase Authenticationで、次を推奨します。
・メール確認：有効
・匿名ログイン：無効
・最低パスワード長：12文字以上
・Site URL：GitHub Pages URL
・Redirect URL：index.html
・利用可能ならCAPTCHAと漏えいパスワード検知を有効

------------------------------------------------------------
6. NFCタグへ書き込む
------------------------------------------------------------
クラウドへ同期すると、メニューに固定URLが表示されます。
そのURLをNFC書込みアプリでURL／URIレコードとして書き込みます。
医療情報を更新しても、公開URLを再発行しない限りタグの再書込みは不要です。

------------------------------------------------------------
7. PDF
------------------------------------------------------------
緊急医療情報画面の「PDFとして保存・印刷」を押します。
ブラウザの印刷画面で「PDFとして保存」を選択してください。
ブラウザの安全制限により、Webアプリが利用者の確認なしで端末へPDFを自動保存することはできません。

------------------------------------------------------------
8. 薬名・指定難病などの候補
------------------------------------------------------------
この版には動作確認用の候補辞書を収録し、候補にない名称は自由入力できます。
全医薬品・全指定難病の最新候補を自動更新する機能は未接続です。
本番運用では、PMDAや厚生労働省の公式データから定期更新する仕組みが必要です。

------------------------------------------------------------
9. 個人情報について
------------------------------------------------------------
・共用端末では使用しないでください。
・端末バックアップJSONは暗号化されていません。
・NFC用URLを知っている人は救急表示情報を閲覧できます。
・公開URLが漏れた場合は、クラウド側で公開リンクを再発行してください。
・一般公開前に、個人情報保護・セキュリティの専門家による確認を推奨します。
